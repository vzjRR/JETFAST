# Diagnostic Rules

The diagnostic phase is read-only.

## Hardware

Collect:

- CPU
- GPU
- RAM
- motherboard
- storage
- network adapters
- display configuration

## Windows

Collect:

- edition
- version
- build
- uptime
- update status
- system health
- event errors

## Gaming

Collect:

- Game Mode
- GPU scheduling
- refresh rate
- VRR
- overlays
- recording
- startup load
- background processes

## Performance

Capture measurable baseline values.

Never fabricate benchmarks.

If a metric cannot be measured:

Mark it:

NOT MEASURED

or:

UNAVAILABLE

Do not estimate it as a measured value.
