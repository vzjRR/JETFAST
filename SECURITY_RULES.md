# Security Rules

The optimization workflow must preserve system security.

Never disable security features merely to increase gaming performance.

Protected components include:

- Microsoft Defender
- Windows Firewall
- Secure Boot
- Memory Integrity
- SmartScreen
- Windows Update

Security-related modifications are HIGH RISK.

They require:

1. Explicit user approval.
2. Explanation of the security impact.
3. Backup where possible.
4. Rollback instructions.
5. Verification.
