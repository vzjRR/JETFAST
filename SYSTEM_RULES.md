# System Rules

## Rule 1 — Read Before Write

All system operations must begin with read-only discovery.

No modification is permitted during initial discovery.

## Rule 2 — User Approval

No optimization may begin without explicit user approval.

## Rule 3 — Backup Before Modification

Whenever a modification is reversible, preserve the previous state first.

## Rule 4 — No Blind Commands

Commands must be targeted and validated before execution.

## Rule 5 — No Security Weakening

Gaming optimization must never require disabling Windows security by default.

## Rule 6 — No Placebo Tweaks

Do not apply undocumented performance tweaks without evidence.

## Rule 7 — Verification

Every important modification must be verified.

## Rule 8 — Rollback

Every reversible modification must have a documented rollback method.

## Rule 9 — Transparency

Never claim that a modification improved performance unless measurements support that conclusion.

## Rule 10 — Privacy

Never collect unrelated personal information.
